## 游戏玩法

### 1️⃣ 开始游戏
在首页滑动屏幕即可开始游戏。

### 2️⃣ 操控小恐龙
左右滑动屏幕控制小恐龙移动，接住从天而降的音符获得分数。

### 3️⃣ 躲避炸弹
小心避开炸弹，否则会失去生命值！

### 4️⃣ 选择曲目
点击音乐按钮，可以选择不同曲目，每首曲目节奏不同。

### 5️⃣ 解锁角色
通过游戏获得金币，解锁更多可爱的小恐龙角色！
